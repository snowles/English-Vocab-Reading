# 英语词汇伴读

把一本英文原版 EPUB 变成「边读边背单词」的版本：正文里在生词后加一个浅色短注，
章节末尾按编号给出完整词条（释义、例句、音标、等级）。

**不改写英文正文、不修改你的原书。** 词库已经随包，不需要你准备词表。
开始之前助手会问你要「初级」还是「高级」：初级在每个自然段后面附「参考译文：…」，
高级只给原文和词注。书名和章节名不翻译，保持原样。
（脚本本身不主动联网；语境判断与译文由你使用的 AI 助手完成。）

---

## 怎么用：对 AI 助手说一句话

在 WorkBuddy / Codex / 豆包工作版等助手里装上这个 Skill，然后直接说：

> 把 `D:\Books\The little prince.epub` 做成伴读版，按雅思词表，输出到 `D:\Books\out`

助手会先问一句「初级还是高级」，再自动完成识别语境、独立审查、出书、校验，
最后只告诉你成品在哪。你不用准备词表，也不用记任何命令。

两档的区别只有一处：

- **初级**：每个自然段后面直接跟一行中文译文，适合刚开始读原版书。
- **高级**：不带中文译文，只留词注，适合想沉浸式读原文。

译文由 AI 助手生成，属于参考，不替换原文；没有把握的段落会如实留空，不会编造。

可以直接说的其它例子：

- 「给这本书标一下四级词汇，正文括注短一点」
- 「先简单标一下，不用管语境」→ 会走词表直注，即**浅标降级版**：只有词表义项、不做
  语境判断、没有独立审查，不能当成正式伴读版。想快也可以先让它出 1 章小样再决定。
- 「只看前两章，做成网页给我预览」

## 你会拿到什么

- 一份**新的** `.epub`，原书一个字节都不动。
- 一份离线阅读页（HTML），双击就能看；两种格式的正文、编号、词条保持一致。
- 正文里的短注按「同一个词 + 同一层意思」去重：每章第一次出现时标注，
  **同词不同义会分别标注**，不打断阅读；完整词条就在这几个自然段后面，
  段落短时几条合并成一组，不用翻到章节末尾去找。

## 常见问题

**词表在哪？要我准备吗？**
不用。它已经跟着 Skill 一起装好了：6861 条，含四级 / 六级 / 雅思三个标签，
运行时自动读取。随包词表由作者本人整理并按 MIT 授权，可自由再分发。
如果你有自己的词表，也可以直接告诉助手用你的——照 `assets/lexicon-template.csv`
的表头填就行（`单词` 与 `中文释义` 两列必填，其余可选）；
自备词表如果带托福 / GRE / 牛津 3000 / AWL 标签，同样能识别和显示。

**提示「原书遗留几处格式瑕疵」是出错了吗？**
不是。那是你**原书自带**的格式瑕疵，工具按兼容策略原样保留，没有替你改原书。
这表示「相对原书没有新增规范问题」，不等于在所有阅读器上都零问题；
具体显示效果取决于你用的阅读器。

**要不要装 Java / EPUBCheck？**
不用。它是可选的官方规范校验工具，装了会自动跑并留档，没装也不影响出书
（会如实写明「未运行」，不会冒充通过）。

**会用我的正文去训练或上传吗？**
脚本只在本机读写文件，不主动调用任何外部模型或 API。但语境判断由你使用的
AI 助手完成——如果那个助手是云端服务，正文会按它自己的规则传输，这部分取决于宿主，
不是本 Skill 能承诺的。

**词条里有什么？**
自然段后面的词条块按编号给完整释义、词性、词表例句，以及音标和中文可读的词形信息。
音标按你在正文里看到的那个词形来标（比如 `fished` 标 `/fiʃt/`，不拿 `fish` 的读音顶替）；
词典没给这个词形读音时就不显示，不会编一个。正文短注只写 `(语境义,[编号])`，不塞等级数字。

**支持哪些书？**
未加密的 EPUB 2 / EPUB 3。不支持 PDF、OCR、DRM 解密，也不做脱离伴读的独立全文翻译。
阅读器方面，本次开发只在离线 HTML 与结构校验层面验证过，
Calibre / Thorium / Apple Books 等具体阅读器尚未逐一验收。

**这个词库能随便转发吗？**
项目代码与文档按 MIT，ECDICT 数据按其 MIT 原文随包；**原始中文词表的权利人授权还没核实**，
封装不等于授权。完整口径与待确认项见 `THIRD_PARTY_NOTICES.md`。
